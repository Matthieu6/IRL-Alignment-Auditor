# Quick Start Guide

This guide will walk you through setting up and running your first IRL-Bayesian experiment.

## Prerequisites

- **Python 3.9+**: The pipeline requires Python 3.9 or higher
- **Conda**: For environment management (Miniconda or Anaconda)
- **CUDA**: Optional but recommended for GPU acceleration
- **8GB+ RAM**: Recommended for smooth operation
- **10GB+ Disk Space**: For models and datasets

## Step 1: Environment Setup

### 1.1 Clone the Repository
```bash
git clone <repository-url>
cd irl-bayesian
```

### 1.2 Run Setup Script
```bash
# Make the setup script executable
chmod +x setup.sh

# Run the setup script
./setup.sh
```

This will:
- Create a conda environment named `irl-bayesian`
- Install PyTorch with CUDA support
- Install all required dependencies
- Install the package in editable mode

### 1.3 Verify Installation
```bash
# Activate the environment
conda activate irl-bayesian

# Verify installation
python -c "import irl_pipeline; print('Installation successful!')"
```

## Step 2: Your First Experiment

### 2.1 Run Complete Pipeline
```bash
# Make sure you're in the irl-bayesian directory
cd irl-bayesian

# Activate the environment
conda activate irl-bayesian

# Run the complete pipeline
./run_pipeline.sh full
```

This will:
1. Generate datasets using default models (Pythia-410M)
2. Train an IRL reward model
3. Save results and visualizations

### 2.2 Monitor Progress
The pipeline will show progress for:
- Dataset generation (loading prompts, generating text)
- Toxicity classification and sorting
- IRL model training (VI steps, accuracy metrics)
- Result saving and visualization

### 2.3 Check Results
After completion, check the outputs:

```bash
# View generated datasets
ls datasets/

# View training outputs
ls outputs/re_irl/

# View the latest results
ls outputs/re_irl/*/round_1/
```

## Step 3: Understanding the Outputs

### 3.1 Generated Datasets
- `*_samples_original.json`: Text generated by the original (toxic) model
- `*_samples_detoxified.json`: Text generated by the detoxified model
- `sorted_toxic_dataset_*.json`: Classified toxic samples
- `sorted_non_toxic_dataset_*.json`: Classified non-toxic samples

### 3.2 Training Results
- `round_{i}/`: Results for each training round
  - `mu.npy`, `sig.npy`: VI posterior parameters
  - `train_history.json`: Training metrics
  - Various plots and visualizations
- `summary.json`: Summary of all rounds

### 3.3 Key Metrics
- **Pairwise Accuracy**: How well the model ranks detoxified vs original text
- **Single-text Accuracy**: Classification accuracy on individual texts
- **AUROC**: Area under ROC curve
- **Calibration Metrics**: Brier score, ECE (Expected Calibration Error)

## Step 4: Customizing Your Experiment

### 4.1 Using Different Models
```bash
# Use smaller models for faster experimentation
./run_pipeline.sh full \
  toxic_model=EleutherAI/pythia-70m \
  non_toxic_model=ajagota71/pythia-70m-s-nlp-detox-checkpoint-epoch-100

# Use larger models for better performance
./run_pipeline.sh full \
  toxic_model=meta-llama/Llama-3.2-1B \
  non_toxic_model=ajagota71/llama-3-2-1b-rlhf-kl-p5-target-2p5-lr-3e-6-checkpoint-epoch-100
```

### 4.2 Adjusting Sample Counts
```bash
# Use fewer samples for quick testing
./run_pipeline.sh full train_samples=500 test_samples=100

# Use more samples for better results
./run_pipeline.sh full train_samples=2000 test_samples=600
```

### 4.3 Modifying Training Parameters
```bash
# Adjust training steps and learning rate
./run_pipeline.sh full \
  training.n_steps=5000 \
  training.learning_rate=0.02 \
  training.alpha=1.5
```

## Step 5: Running Individual Components

### 5.1 Dataset Generation Only
```bash
# Generate datasets without training
./run_pipeline.sh generate

# With custom parameters
./run_pipeline.sh generate \
  toxic_model=EleutherAI/gpt-neo-125m \
  train_samples=1000
```

### 5.2 IRL Training Only
```bash
# Train IRL model on existing datasets
./run_pipeline.sh train

# With custom parameters
./run_pipeline.sh train \
  training.n_steps=3000 \
  training.learning_rate=0.01
```

## Troubleshooting

### Common Issues

#### 1. CUDA Out of Memory
```bash
# Use smaller models or reduce batch size
./run_pipeline.sh full \
  toxic_model=EleutherAI/pythia-70m \
  training.batch_size=16
```

#### 2. Missing Dependencies
```bash
# Reinstall dependencies
conda activate irl-bayesian
pip install -r requirements.txt
```

#### 3. Permission Errors
```bash
# Make scripts executable
chmod +x setup.sh run_pipeline.sh scripts/*.py
```

#### 4. Dataset Not Found
```bash
# Check if datasets were generated
ls datasets/

# Regenerate if needed
./run_pipeline.sh generate
```

### Getting Help

1. **Check Logs**: Look at the console output for error messages
2. **Verify Environment**: Ensure conda environment is activated
3. **Check Dependencies**: Verify all packages are installed
4. **Review Configuration**: Check config files for correct paths
